# Mapa de referencia sin servicios externos

Datos: Natural Earth, tierra a escala 1:110 millones, dominio público.

- Fuente: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- Licencia: https://www.naturalearthdata.com/about/terms-of-use/

- land-rings.json: contornos exteriores, redondeados a cuatro decimales para reducir tamaño.

Se incluye tierra y costa simplificadas, sin calles, fronteras ni ciudades.
No es cartografía de navegación ni un mapa de intensidad o zona afectada.
El dibujo se genera localmente; no solicita teselas ni transmite posiciones a un proveedor de mapas.
